# 🎧 Spotify Clone

A front-end clone of Spotify's web player, built with pure **HTML & CSS**. It recreates the core look and feel of Spotify — sidebar navigation, playlists, a "Recently Played" / "Top Hits" browsing grid, a Premium subscription section, and a fully styled bottom music player bar.

**🔗 Live Demo:** [spotify-clone-sandy-eta.vercel.app](https://spotify-clone-sandy-eta.vercel.app)

## ✨ Features

- **Top Bar** — Spotify logo, a search input, and Log In / Sign Up buttons
- **Sidebar Navigation** — Home, Search, Your Library, and a Playlists section (Chill Vibes, Workout Mix, Study Focus, Throwback Hits)
- **Music Browsing** — "Recently Played" and "Top Hits" card grids with album art, song titles, and artist names
- **Go Premium Section** — Toggle between Free and Premium plans, each with its own feature list, plus an email sign-up form
- **Bottom Player Bar**
  - Now-playing track info with album art
  - Playback controls (shuffle, previous, play/pause, next, repeat)
  - Animated progress bar
  - Volume slider
- **Pure CSS Interactivity** — Play/pause toggle and plan selection are handled with checkbox/radio inputs and CSS — no JavaScript required
- **Custom Fonts** — Uses Google Fonts (Poppins & Inter) for a clean, Spotify-like typography

## 🚀 Getting Started

No build tools, package managers, or dependencies required — this is a static site.

1. **Clone the repository**
   ```bash
   git clone https://github.com/Tanmay2006-Tech/Spotify-Clone.git
   cd Spotify-Clone
   ```

2. **Open it locally**

   Simply open `index.html` in your browser, or for the best experience, serve it with a local dev server (e.g. VS Code's **Live Server** extension) so fonts and assets load correctly.

3. **That's it!** No `npm install`, no build step — just static HTML & CSS.

---

## 🌐 Deployment

This project is deployed on **Vercel**. To deploy your own copy:

1. Push your fork to GitHub
2. Go to [vercel.com](https://vercel.com) and import the repository
3. Leave the build settings as default (static site) and deploy
